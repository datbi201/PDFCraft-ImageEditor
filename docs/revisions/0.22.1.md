# My PDFCraft Rev 0.22.1

- Window controls keep their regular pointer. The empty space between the top bar's controls also moves the window and supports double-click to maximize or restore.
- Narrow windows put the main menus and workspace tabs on separate rows. Open and command search use compact buttons when space is limited.
- All tools reopens its panel even when the saved layout no longer has a position for it. The Tools panel adapts to available width and keeps its preferred width for larger windows.
- Short windows show page navigation and zoom below the document, leaving space for the inspector icons. The floating quick toolbar scrolls when its buttons extend past the window.
- Edit has a direct **Edit text & images** button and one panel header.
- Ctrl+wheel zoom starts on the first notch. With animation enabled, the view scales its current page image while zoom changes and requests the sharper raster as the zoom settles.
